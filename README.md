# Retail Business Performance & Profitability Analysis

## 📌 Project Overview

This project analyzes retail FMCG sales and inventory data to evaluate business performance, profitability, sales trends, and inventory-related indicators.

The analysis uses Python, SQL, and Power BI to transform transactional data into meaningful business insights and an interactive dashboard.

---

## 🎯 Project Objective

- Analyze revenue, cost, profit, and units sold
- Identify profit-driving and profit-draining categories
- Analyze brand and category performance
- Examine monthly sales and profit trends
- Compare sales across cities, channels, and store formats
- Analyze inventory levels and reorder indicators
- Present insights through an interactive Power BI dashboard

## 📊 Dataset

**Dataset:** Indian FMCG Retail Sales Customer Inventory (2024)

The dataset contains information related to:

- Sales transactions
- Products and brands
- Categories
- Revenue and cost
- Profit margin
- Inventory levels
- Reorder levels
- Lead time
- Customer information
- Sales channels
- Store formats
